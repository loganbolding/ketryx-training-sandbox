# Ketryx training sandbox

Fictional sample data for recording Ketryx training videos: Git-based requirements and
specifications (`src/**/*.md`), Cucumber tests and npm dependencies, copied from Ketryx's public
[git-based-items-best-practices](https://github.com/Ketryx/git-based-items-best-practices) example.

Training takes change files here and Ketryx syncs the change. Before every take the `main` branch
is reset to the `base` tag, so history after `base` is rewritten. Nothing here is real product or
customer data. Safe to delete.
